# Awaken Church — Releases

Public downloads for the Awaken Church mobile app. No application source
code lives here — just built release binaries, published via GitHub
Releases.

## Android

The Google Play Developer account for this app was terminated (Google's
final decision, not appealable further: related-account enforcement). The
Android app is distributed as a direct-install APK instead.

**[Download the latest Android APK](https://github.com/VernonAddPay/awakenchurch-releases/releases/download/android-latest/awaken-church.apk)**

You'll need to allow "install from unknown sources" for your browser or
file manager app when installing it — that's expected for an app
installed outside the Play Store.

This link is stable: it always points to the current release, even after
future updates.
